# flogger
Скачайте ZIP-файл репозитория
2. Разархивируйте его в любую папку
3. Зайдите в папку server -> найдите файл HttpServer.csproj -> запустите программу -> в поисковой строке браузера впишите http://127.0.0.1:8888/connection/
4. для проверки верстки найдите одноименный файл -> просмотрите сайты. Если не разархивировать, то картинки не будут грузиться
